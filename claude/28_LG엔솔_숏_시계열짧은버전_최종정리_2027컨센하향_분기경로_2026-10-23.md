# 28. LG엔솔 숏 「시계열 짧은 버전」 최종 정리: 2027 컨센은 이미 꺾이기 시작했다 (2026-10-23)

## 결론 (먼저)

1. **26번 1순위 질문이 풀렸고, 답은 숏 쪽이다.** 3Q 서프라이즈(10/8) 뒤 1개월 동안 증권사들은 **앞으로 올 모든 분기의 영업이익을 내렸다.** 4Q26E -3.9%, **1Q27E -13.5%**, 2Q27E -6.3%, 2027E 연간 -4.4%. 올라간 건 이미 지나간 3Q가 들어간 2026E(+17%)뿐이다(도표 11).
2. **2027E는 매출을 올리고 이익을 깎는 중이다.** 1개월 새 매출 +1.1%, 영업이익 -4.4%, 영업이익률 9.6% → 9.1%. 1년 전에는 매출 34.5조, 영업이익 5.15조(이익률 14.9%)였다. **물량은 믿고 마진은 의심하기 시작했다.** 우리 전장(본업 이익률, 20·26번)과 같은 방향이다(도표 10).
3. **2027E도 앞선 3년과 같은 길에 들어섰다.** 1년 새 5.15조 → 3.82조(-26%). 2024(-78%), 2025(-15%), 2026(-54%) 모두 연초 컨센이 실제보다 높았다(도표 12).
4. **하반기 쏠림은 가정이 아니라 컨센에 들어 있다.** 1Q27E 6,508억 + 2Q27E 8,184억 = 상반기 1.47조(연간의 38%). 연간 3.82조를 맞추려면 **하반기 분기 평균 1.18조**가 필요하다. 3Q26 실제(보상금 포함) 7,560억의 1.6배, AMPC 제외 3,391억의 3.5배다(도표 13). 25번에서 "가정 위의 가정"으로 판정한 표를 실제 컨센으로 대체한다.
5. **주가는 아직 이걸 반영하지 않았다.** 주가는 3Q 잠정 전날(391,000원)과 거의 같은 수준이고, 2027E PER은 45.9배다. 컨센이 빠지는데 멀티플은 그대로다.
6. **판단: 이번 주에 롱(한양이엔지) 대신 써도 된다.** 보고서로는 좋다. 매매로는 손익비(-27% vs +23%)와 공매도 잔고 1위 때문에 미들리턴·하이리스크다.

### 1-3. 읽는 법과 조심할 점

- **2026E 연간(9,967억)은 아직 낡은 숫자다.** 분기 실적·컨센을 더하면 -2,078 + 1,133 + 7,560 + 6,087 = **12,702억**이다. 증권사들이 3Q 잠정을 반영하면 2026E는 **기계적으로 +27% 더 오른다.** 발표 Q&A에서 "컨센이 오르고 있다"는 반론이 나오면, 오르는 건 이미 지나간 3Q(보상금 포함)이고 **앞으로 올 분기는 전부 내려가고 있다**고 답한다(도표 11).
- **분기 컨센은 연간보다 참여 증권사가 적다.** 숫자 하나하나보다 "방향이 전부 아래"를 쓴다.
- **2027E는 영업이익을 내리면서 순이익을 올렸다**(1개월: 영업이익 -4.4%, 지배순이익 +3.2%, EPS +3.2%). 1Q27E도 영업이익 -13.5%인데 순이익은 -1,180억에서 +2,748억으로 바뀌었다. 영업외(비지배 몫·이자·세금) 가정이 바뀌었거나 참여 증권사가 바뀐 것으로 보인다. **확인 못 함.** PER 45.9배가 이 EPS 위에 있다는 점은 18번(비지배 이익 하향 다리)과 연결된다. 보고서에서는 영업이익 기준으로 말하고, EPS는 밸류 계산에만 쓴다.

## 5. 밸류에이션 (23·25·26번 정합)

| 방식 | 계산 | 결과 |
|---|---|---|
| 메인: 2027E 지배 EPS × PER | 컨센 EPS 8,494원 × (1 - 20%) = 6,795원 × PER 41~45배 | **27.9~30.6만원** |
| 교차 1: 본업 이익률 역산(20번) | 본업 이익률 7.2%(역대 최고 4.7%의 1.5배)를 인정 | 28만원 |
| 교차 2: Bloomberg 피어 PER(25번) | 2027E 피어 평균 14.8배 적용 시 현재가는 본업 이익률 14.6%를 요구 | 참고 |
| **목표가** | | **28만원(-27%)** |

- -20%의 근거: 2027E ESS 본업 이익률 0%(삼성 2.5% 대비) 가정(20번). 오늘 확인한 컨센 이익률 하향(9.6% → 9.1%)은 이 방향이 이미 시작됐다는 보조 근거다.
- PER 41~45배는 현재 멀티플을 유지해 준 숫자다. 멀티플까지 내려가면 하방은 더 크다(부록).
