# 32. 미래에셋 「'각' 나온다」 원문 검증 + 롱 목표가 브릿지 + 10월 3주 위클리 뉴스 (2026-10-24)

- 입력(사용자 업로드):
  - 미래에셋증권 2차전지 「'각' 나온다」(2026-05-26, 비중확대 유지, 김철중·정세훈, 53쪽, 이미지로 판독)
  - LS증권 이차전지 위클리 표1 「주간 주요 News(10월 3주)」 캡처
- 읽은 범위: 요약(3~4쪽), ESS 수요(11~22쪽), 멀티플 변수(35~36쪽), 탑픽(37쪽), 삼성SDI(39~41쪽), **LG에너지솔루션(42~44쪽)**
- 도표: `claude/charts/16_북미ESS_롱vs숏_가정.png`, `claude/charts/17_미래에셋목표가_브릿지.png`
- 앞 문서: 20(AMPC 현재가치 19.5조), 25(공장별 생산), 28(최종 정리), 29(블로그 뷰), 31(LS 원문)

## 결론 (먼저)

1. **롱 쪽 목표가의 40%가 보조금이다.** 미래에셋 LG엔솔 목표가 58만원은 2027F EBITDA에 EV/EBITDA를 곱한 합산이다. 그중 **2027년 한 해 AMPC 2.44조에 15~25배를 곱한 값이 54조원, 주당 약 23만원(40%)**이다. 보조금은 2030년부터 줄고 2033년 0이다(15번). → **"지대에 해자 멀티플"(29번)을 롱 리포트 자기 숫자로 보여 주는 표**다. 이번 작업에서 나온 가장 강한 재료다.
2. **같은 모델에서 세 줄만 바꾸면 33.6만원(-12%)이 나온다**(도표 17).
   - AMPC를 일몰 반영 현재가치(19.5조, 20번)로 바꾸면 -14.8만원
   - ESS 본업 이익률 3.8% → 0%(20번 가정): -5.9만원
   - ESS 본업 멀티플 25배 → 15배(EV 사업부와 같은 수준): -3.5만원
   - 비지배지분(합작사 몫)을 빼지 않은 점은 추가 하방인데, 반영하지 않았다.
   - **정직하게 쓸 것:** 이 브릿지는 33.6만원에서 멈춘다. 우리 목표가 28만원까지 가려면 물량 가정(아래 3번)도 틀려야 한다.
3. **롱 쪽 2027 물량은 "북미 ESS 중국산 점유율 90% → 28%"를 전제한다**(도표 16). 미래에셋 표3: 비중국 점유율 2025년 10% → 2026년 50% → **2027년 72%** → 2028년 85%, LG엔솔 북미 ESS 출하 2026년 37 → **2027년 50GWh**. LS는 중국산이 "당분간 70%대"를 유지한다고 봤다(31번). **블로그가 말한 LS vs 미래에셋 논쟁의 핵심 숫자가 이것이다.**
4. **롱 쪽 분기 추정은 이미 크게 빗나갔다.** 미래에셋 2Q26F 영업이익 2,882억 → 실제 1,133억(-61%). 3Q26F 6,520억 → 실제 7,560억(보상금 포함). 다만 LS도 2Q를 -1,030억으로 너무 낮게 봤다. 두 쪽 다 틀렸다는 점을 같이 쓴다.
5. **위클리 뉴스 중 우리 논지에 영향을 주는 것은 두 개다.**
   - **LFP 양극재 국산 조달 협상(10/16):** LG엔솔이 포스코퓨처엠·엘앤에프와 계약 막바지라는 보도. → **2028 MACR 절벽 가설(25번 5장)은 약해진다**(부록에서 빼거나 "회사가 대응 중"으로 고친다). 대신 국산 양극재는 원가가 높다(17번: +$6.6/kWh) → **본업 이익률 논지(전장)는 오히려 강해진다.**
   - **S&P "韓 배터리, 보조금 없는 미래 직면…LG엔솔에 타격"(10/20):** 신용평가사가 공개적으로 같은 말을 했다. 1층(시장이 아는 것) 근거로 인정 단계에 쓴다. 원문 리포트는 미확인.

## 2. 브릿지: 롱 모델 → 우리 가정 [도표 17]

| 단계 | 바꾸는 것 | 근거 | 주당(천원) | 누적 |
|---|---|---|---|---|
| 0 | 미래에셋 모델값 | 표9 | | 577 |
| 1 | AMPC 54.0조(연결, 2027년 1년치 × 15~25배) → 19.5조(주주 몫, 2032년까지 일몰 반영 현재가치, 5% 할인) | 20번(삼성 숫자 기준) | -148 | 430 |
| 2 | ESS 본업 이익률 3.8% → 0%(본업 영업이익 552십억 제거, 감가상각은 유지) | 20번 가정 | -59 | 371 |
| 3 | ESS 본업 멀티플 25배 → 15배(같은 모델의 EV·소형 배수) | 미래에셋 표9 | -35 | **336** |
| (참고) | 비지배지분 미차감(합작사 GM·혼다·현대 몫, 2027F 비지배순이익 582십억) | 미래에셋 44쪽 | 미반영 | 추가 하방 |

- **1단계 하나만으로 43만원이 된다.** 보조금 처리 하나가 롱 목표가의 차이 대부분을 만든다.
- 3단계 결과 33.6만원은 현재가(38.3만원) 대비 -12%다. 우리 목표가 28만원(-27%)과의 차이는 **물량**(롱 모델 북미 ESS 50GWh, 중국산 28%)에서 나온다. 보고서에는 "롱 모델의 물량을 그대로 받아도 33.6만원"으로 쓰고, 28만원은 "물량까지 LS 쪽으로 가면"의 결과로 둔다.
- **조심할 점:** 19.5조는 삼성증권 숫자 기준 현재가치이고(20번), 미래에셋 AMPC 경로와 다를 수 있다. 1단계는 "같은 숫자를 일몰 반영해 다시 계산하면"이 아니라 "다른 증권사 숫자로 계산한 일몰 반영 가치로 바꾸면"이다. 보고서에서 이 차이를 각주로 밝힌다.

## 3. 북미 ESS: 롱 vs 숏 쪽 가정 [도표 16]

| 2027 | 미래에셋(Buy, 5/26) | LS(Hold, 5/12) |
|---|---|---|
| 북미 ESS 시장 | 125GWh | 102GWh |
| 중국산 점유율 | **28%**(2025 90%) | "70%대 유지"(2025 Wood Mac 72%) |
| 비중국 셀 몫 | 90GWh | 31~57GWh |
| LG엔솔 북미 ESS 출하 | **50GWh**(2026 37) | 별도 추정 없음. 2027E ESS 매출 9.1조(+20%) |
| 삼성증권(10/8) 참고 | LG엔솔 미국 ESS 라인 생산 38GWh | |

- 같은 2025년을 미래에셋은 중국산 90%, Wood Mackenzie(LS 인용)는 72%로 본다. 기준(유틸리티만 vs 전체)이 다르다.
- **채점 가능한 숫자:** 미래에셋은 2026년에 이미 비중국 50%, LG엔솔 북미 ESS 37GWh를 가정했다. **11/3 컨콜과 1월 4Q 실적에서 LG엔솔 2026년 북미 ESS 출하가 37GWh에 못 미치면 롱 쪽 2027 가정(50GWh)이 흔들린다.** → 11/3 컨콜 질문에 "2026년 미국 ESS 출하량(GWh)"을 넣는다.
- 미래에셋 수주잔고 경로: 2Q25 50 → 3Q25 120 → 4Q25 140 → 1Q26 140 → **2026년 말 190GWh(예상)**. 1Q26에 멈췄다. 연말 190GWh 달성 여부도 채점 항목이다.
