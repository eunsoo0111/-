# 29. 외부 뷰 검토: "버려지는 전기가 만든 ESS 시장" + "지대 vs 해자"(LS Sell vs 미래에셋 Buy) (2026-10-23)

- 입력: 사용자가 붙여 넣은 글(블로그형, LS증권 셀 리포트와 미래에셋 2차전지 리포트를 읽고 쓴 메모)
- 질문: 이 뷰를 우리 LG엔솔 숏(28번)에 어떻게 쓰나
- 기준 문서: 28(최종 정리), 23(재료 창고·3층 지도), 26(먼 미래는 촉매가 아니다)

## 결론 (먼저)

1. **방향은 우리와 같고, 프레임으로는 아주 좋다. 하지만 이 뷰는 "1층(시장이 아는 것)"이다.** LS증권이 이미 숫자까지 써서 냈고, 업종 전체 얘기라 LG엔솔 목표가가 안 나온다. 그대로 가져오면 보고서가 "비싸다 + 먼 미래" 숏으로 돌아간다. 26번에서 버린 길이다.
2. **가져올 것은 세 가지다.**
   - **"지대에 해자 멀티플을 주고 있다"**: 투자포인트 2(보조금 이익에 PER 46배)의 이름표로 쓴다. 우리가 숫자로 하는 일(AMPC와 본업 분리)을 한 단어로 설명해 준다.
   - **"셀은 병목이 아니다"**: 중국 턴키 vs 미국 가격 차이가 셀이 아니라 셀 밖(PCS·변압기·EPC·SI)에서 난다. → **미국 ESS의 높은 가격을 셀 회사가 가져가지 못한다**는 근거. 우리 "2027 ESS 본업 이익률 0%" 가정의 정성 근거가 된다.
   - **"이 논지가 틀리려면 해자의 증거가 나와야 한다"**: 우리 손절 조건(ESS 본업 이익률 8% 이상 한 분기)이 바로 그 증거다. 손절선을 "지대가 해자로 바뀌었다는 증거"로 설명하면 리스크 장이 깔끔해진다.
3. **새로 잡아야 할 리스크 하나: 미국 중간선거가 11/3이다.** LG엔솔 3Q 컨콜과 같은 날이고, 우리 발표(10/31) 사흘 뒤다. 미래에셋 논지의 핵심 변수가 "중간선거 → IRA 부활 기대 → 섹터 멀티플"이다. 민주당이 이기면 단기 급등 가능성이 크다. 28번 리스크 표에 넣고, 발표에서 먼저 인정한다.
4. **그대로 쓰면 안 되는 숫자가 여럿이다**(2장). 특히 "LG엔솔 2026E PER 63.8배"는 현재 컨센(2026E 순이익 적자 → PER 없음, 2027E 45.9배)과 맞지 않는다.

## 1. 뷰를 우리 논리 사슬에 대보기

| 뷰의 주장 | 우리 문서에 이미 있나 | 판정 | 쓰는 곳 |
|---|---|---|---|
| ESS 수요는 진짜고 가격 비탄력적이다(출력제한, firm capacity 경매, 저장 의무화) | 23번 "인정" 단에 "수요는 진짜"만 있음 | **보강용으로 좋음** | 1장 "인정". 수요 쪽은 롱 숫자를 받는다는 우리 원칙과 맞는다 |
| 셀은 병목이 아니다. 진짜 병목은 전력망(대기열 1,700GW, 리드타임 5~10배) | 없음 | **새 정성 근거** | 투자포인트 2: "수요가 늘어도 셀 마진은 안 늘어난다(태양광 모듈 선례)" |
| 중국 턴키 $62 vs 미국 $219, 차이는 셀 밖에서 난다 | 23번 "테슬라 30%는 시스템 마진, LG엔솔은 셀" | 같은 논리, **숫자 출처 확인 필요** | 투자포인트 2 근거 표 한 줄 |
| 전력망 연결 지연 → 고객 인수 지연 → 가동률 하락 → AMPC(생산량 비례) 감소 | 없음 | **새 각도, 증거 없음** | 리스크/부록. 11/3 컨콜 질문: "고객 인수 지연으로 출하가 밀린 사례가 있나" |
| 지대의 세 제한: 시간(정치) / 마진(LFP 범용화) / 공간(미국 18%) | 시간 = 45X 일몰(15번), 마진 = 본업 이익률(20번), 공간 = 없음 | **프레임으로 좋음** | 투자포인트 2의 구조. 단 "시간"은 각주(26번 원칙) |
| 미국 ESS 내 비중국 점유율 10% → 50%(2026) → 85%(2028)(미래에셋) | 없음 | **롱 쪽 핵심 가정** | 반대 논리 1번. 우리 답: "점유율 85%를 그대로 받아도 싸움터는 마진" |
| 한국 셀 3사가 CATL·BYD보다 2~4배 비싸다 | 25번 Bloomberg 피어 PER 14.8배 | **1층.** "비싸다"만으로는 숏 논지가 아니다 | 밸류 교차 확인 한 줄만 |
| 시장 점유율 하락, LFP·각형 표준화, 뒤늦은 CAPEX 악순환 | 일부(17번 LFP 양극재) | 1층, 장기 | 쓰지 않거나 배경 한 문단 |
| 2028 대선에서 규제 소멸 가능 | 25번 "2032 일몰은 각주" | **먼 미래.** 촉매 아님 | 각주 |
| 지대 → 해자 전환 반론(한국 반도체, TSMC, 삼성SDI 각형) | 19번 레드팀 | 좋은 반론 | 리스크 장: "전환의 증거 = 손절 조건" |

## 2. 그대로 쓰면 안 되는 숫자

| 글의 숫자 | 문제 | 처리 |
|---|---|---|
| LG엔솔 2026E PER 63.8배 | 현재 컨센 2026E 지배순이익 -2,421억 → PER 없음. 2027E 45.9배(28번) | **우리 숫자(2027E 45.9배)만 쓴다** |
| 글로벌 ESS 수요 624GW, 데이터센터 36GW | 단위가 GW와 GWh로 섞여 있다(원문 리포트는 GWh) | 원문 리포트에서 단위 확인 |
| "45GW × 0.25 = 9~14GW" | 계산이 맞지 않는다. 180GW × 25% = 45GW(저장 의무 프로젝트), 여기에 ESS 비율 20~30%를 곱해야 9~14GW | 인용하지 않는다 |
| 삼성SDI 점유율 12% → 3% | 기준(전체 EV인지, 특정 시장인지)이 불분명하다 | 쓰지 않는다 |
| 중국 턴키 $62/kWh, 미국 $219, 유럽 $177 | BNEF 인용이라고 하지만 연도·범위(시스템 범위)가 안 적혀 있다 | 원문 확인 후 사용 |
| 미국 ESS 중 중국산 72%(2025) | LS 리포트 인용 | LS 원문 페이지 확인 후 사용 가능 |
| 이란전쟁·호르무즈 3개월 봉쇄 | 이 글의 전제. 우리 문서에는 반영 안 됨 | 리스크 장에 거시 변수로 한 줄 |

## 3. 28번 보고서에 반영할 것

| 자리 | 반영 내용 |
|---|---|
| 1. 인정 | "ESS 수요는 출력제한과 저장 의무화가 만든, 가격에 둔감한 수요다." 수요를 확실히 인정할수록 "그런데 마진은"이 산다 |
| 투자포인트 2 제목 | **"지대에 해자 멀티플"**: 2027E 이익의 대부분이 보조금(정책이 만든 지대)인데 PER 46배(성장주·해자 멀티플)를 받는다 |
| 투자포인트 2 근거 | 미국 ESS 가격 프리미엄은 셀 밖(PCS·EPC·SI)에서 난다 → 셀 회사의 본업 이익률은 안 오른다. 태양광 모듈 선례(시장 10배, 비중국 업체 대부분 퇴출) |
| 리스크 표 | **11/3 미국 중간선거(같은 날 3Q 컨콜)**, 호르무즈·유가, 데이터센터 ESS 성장, 비중국 점유율 급등(미래에셋 85%) |
| 손절 설명 | "지대가 해자로 바뀌었다는 증거"가 나오면 커버: ESS 본업 이익률 8% 이상 한 분기, 분기 본업 영업이익 5,000억 이상, 종가 47만원 |
| 반대 논리 | "점유율이 85%가 돼도 우리는 물량 가정을 롱 쪽(삼성증권) 숫자로 받는다. 싸움터는 마진 하나다" |
